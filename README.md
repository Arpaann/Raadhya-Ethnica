# Raadhya Ethnica

> **Authentic Indian Ethnic Wear. Crafted with passion and elegance, celebrating every woman, every occasion.**

A complete, premium, responsive luxury e-commerce web application for **Raadhya Ethnica**, headquartered in Kathmandu, Nepal. Designed in the architectural, quiet-luxury visual aesthetic of Louis Vuitton.

![Raadhya Ethnica Logo](logo.png)

---

## ✦ Highlights

- **Boutique Visual Identity**: Architectural typography with Google Fonts `Bodoni Moda` (display serif) and `Jost` (geometric sans). Hairline borders, square-cornered buttons, and an antique bronze accent.
- **Full Light & Dark Theme**: Seamless toggle with persistent preference and automatic logo adaptation.
- **Louis Vuitton Homepage Structure**:
  1. Full-width hero ("The Festive Edit") with stacked editorial links.
  2. "Explore a selection of the maison's creations" (6 category tiles).
  3. Horizontal product rails for *New Arrivals* and *Everyday Cotton*.
  4. "Seen on Instagram" vertical reel-style cards linked directly to [@raadhya_ethnica](https://www.instagram.com/raadhya_ethnica/).
  5. "The Maison Raadhya Ethnica" with 3 heritage editorial tiles.
  6. Stats & services trust strip (Encrypted Checkout, Free Shipping over A$150, 7-Day Returns, Certified Authenticity).
  7. Private list newsletter (10% first order invitation with code `WELCOME10`).
  8. Architectural footer with collections, boutique details, payment badges, and social links.
- **Sitewide Features**:
  - Rotating announcement bar.
  - Sitewide promo film band with looping muted scenes, progress bar, play/pause controls, and Instagram post links.
  - Floating WhatsApp concierge (`+977 9869100969`) with pre-filled inquiries.
- **Shop & Client Features**:
  - Hash-based SPA routing (`#home`, `#shop`, `#product`, `#maison`, `#contact`, `#care`, `#bag`, `#wishlist`, `#account`).
  - Interactive color swatches on Product Detail Pages that dynamically recolour garment previews.
  - Size selector (XS–XXL) with size guide modal.
  - Shopping Bag with real-time Free Shipping progress meter towards A$150 and promo code `WELCOME10`.
  - Client Wishlist saved in `localStorage`.
  - Contact form with required fields and owner verification notes.

## ✦ Local Development

Run with any local static HTTP server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
